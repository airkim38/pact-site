HOW IT WORKS

뭉치면 달라지는 3단계

이슈를 등록하면 AI가 분석하고,
사람이 모이면 압박이 시작됩니다.

01
문제 상황을 입력한다
학습한 AI가 왜 안 됐는지부터 분석합니다. 관련 법령, 유사 판례, 최적 채널을 자동으로 파악합니다.
02
사람을 모은다
링크 하나로 집단이 됩니다. 같은 처지의 사람들이 서명하고, 함께 움직입니다.
03
동의하거나 거부한다
나머지는 AI가 실행합니다. 문서 생성, 발송, 에스컬레이션까지 자동으로 진행합니다.
WHY PACT

분석 도구가 아닌, 실행 에이전트입니다

기존 청원·서명 플랫폼은 목소리를 모으는 데서 끝납니다.
Pact AI는 전략을 세우고, 문서를 만들고, 발송하고, 무응답이면 다음 단계를 자동 실행합니다.

기존 방식
✕혼자 항의해봐야 "검토하겠다"는 말만 돌아옵니다
✕청원·서명까지 해도 상대방은 그냥 무시합니다
✕한 채널에 집중하면 상대방은 그 채널만 막습니다
✕법 지식이 없으면 어디에 뭘 내야 할지 모릅니다
✕대표자가 멋대로 합의해버리는 위험이 있습니다
PACT AI 에이전트
✦복합 문제를 법령 레이어별로 분해 — 채널 자동 설계
✦1단계 통보 → 무응답 시 전 채널 동시 압박 자동 실행
✦기관 민원 + 국회의원 + 언론 — 모든 방향이 동시에
✦관할 기관·법령·제출 서식까지 AI가 자동 파악
✦합의문도 참여자 투표로 결정 — 대표자 독단 불가
LEARNED AI

범용 AI와 결정적으로 다릅니다

범용 AI는 모든 분야를 조금씩 압니다.

PROCESS

해결까지의 여정

등록부터 합의 도출까지,
Pact AI가 모든 단계를 실행합니다.

PHASE 01
이슈 등록 & 집단 구성
문제 상황을 입력하면 AI가 분석하고, 링크를 공유해 같은 처지의 사람들을 모읍니다.
완전 무료
1단계
공식 통보
AI가 생성한 공식 문서를 상대방에게 발송합니다. 응답 기한을 설정하고 대기합니다.
무료
2단계
동시다발 전 채널 압박
무응답 시 관할 기관, 국회의원, 언론사 등 모든 채널에 동시 발송합니다.
해결동참
3단계
Pact AI 직접 실행
내용증명, 진정서, 고소장, 고발장, 소장까지 — AI가 직접 생성하고 실행합니다.
추가 비용 없음
RESOLUTION
합의 도출
합의문을 AI가 생성하고, 참여자 투표로 최종 결정합니다. 대표자 독단이 불가능합니다.
합의 완료
AI AGENT ENGINE

8개 엔진으로 작동합니다

목표를 받으면 계획을 세우고, 문서를 만들고, 발송하고,
무응답이면 다음 단계를 자동 실행합니다.

ENGINE 01
복합 이슈 분해
Issue Decomposition
막연한 문제를 법령 레이어별로 자동 분해합니다.
ENGINE 02 진화 중
동적 채널 매핑
Channel Mapping
채널 실행 DB 기반 관할기관·국회의원·언론사를 자동 조합합니다.
ENGINE 03
채널별 문서 생성
Document Generation
협상 요청서·민원서·보도자료를 채널 형식에 맞게 자동 생성합니다.
ENGINE 04
집단 의견 분석
Opinion Analysis
참여자 의견을 자동 분류·집계해 핵심 요구사항 우선순위를 도출합니다.
ENGINE 05
합의문 생성
Agreement Generation
협상 경과와 요구사항을 바탕으로 합의문 초안을 자동 작성합니다.
ENGINE 06
증빙 분석
Evidence Analysis
증빙자료를 분석해 요약 텍스트를 생성합니다.
ENGINE 07
협상 전략 추천
Strategy Recommendation
상황에 맞는 협상 전략과 대응 시나리오를 제안합니다.
ENGINE 08 진화 중
학습 기반 전략 추론
Strategy Inference Engine
범용 AI와 결정적으로 다른 엔진입니다. 축적된 판례·언론·성공·실패 데이터를 학습한 AI가, 왜 안 됐는지부터 먼저 분석하고 실제로 통하는 전략을 설계합니다.
엔진 08 작동 흐름
이슈 텍스트 + 서명자 수 입력
↓
왜 안 됐는가 — 과거 실패 패턴 분석
↓
서명자 수 × 상대방 유형으로 전략 강도 산출
↓
채널 우선순위 + 실행 전략 + 한 줄 요약
