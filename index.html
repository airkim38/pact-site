PACT의 AI, 이렇게 도와드립니다
법 지식도, 협상 경험도 없어도 괜찮아요. PACT의 AI 엔진 4종이 처음부터 끝까지 함께합니다.
Engine 01
AI 이슈 구조화
Issue Structuring Engine
입력한 문제를 AI가 즉시 분석해 협상 가능한 구조로 변환합니다. 문제 유형 분류, 상대방 분석, 관련 법령 탐색, 요구사항 초안까지 자동으로 제안합니다.
분석 예시
입력: "포괄임금제로 야근을 공짜로 시켜요"
→ 문제 유형: 노동 문제
→ 관련 법령: 근로기준법 제56조
→ 추천 요구사항: 포괄임금제 폐지 / 초과근로수당 지급
Engine 02
AI 집단 의견 분석
Collective Opinion Engine
수백 명의 참여자 의견을 AI가 자동으로 분류하고 핵심 요구사항을 도출합니다. 집단의 목소리를 놓치지 않고 우선순위를 정확하게 정리합니다.
분석 예시
참여자 500명 · 댓글 900개 분석 결과
→ 1위: 초과근로수당 지급 (68%)
→ 2위: 포괄임금제 폐지 (52%)
→ 3위: 근로시간 기록 시스템 (41%)
Engine 03
AI 협상 문서 생성
Document Generation Engine
집단의 요구사항을 바탕으로 공식 협상 문서를 자동 생성합니다. 협상 요청서, 공식 요구서, 합의문 초안까지 — 법적 형식에 맞게 바로 활용할 수 있어요.
생성 가능 문서
협상 요청서 / 공식 요구서
협상 제안서 / 합의문 초안
내용증명 초안 (전문가 검토 권장)
Engine 04
AI 협상 전략 추천
Strategy Recommendation Engine
이슈 유형과 상황에 맞는 최적의 협상 전략을 단계별로 안내합니다. 어떤 순서로 어떻게 대응해야 할지 AI가 시나리오를 제시합니다.
전략 추천 예시
1단계: 공식 협상 요청서 전달
2단계: 노동청 신고 병행
3단계: 집단 공개 압박
4단계: 집단 소송 준비
