Why Pact
분석 도구가 아닌, 실행 에이전트입니다
기존 청원·서명 플랫폼은 목소리를 모으는 데서 끝납니다. PACT의 AI는 문제를 받아 전략을 세우고, 문서를 만들고, 채널에 발송하고, 무응답이면 다음 단계를 자동으로 실행합니다.
기존 방식
✕혼자 항의해봐야 "검토하겠다"는 말만 돌아옵니다
✕청원·서명까지 해도 상대방은 그냥 무시합니다
✕한 채널에 집중하면 상대방은 그 채널만 막으면 그만입니다
✕법 지식이 없으면 어디에 어떻게 신고해야 할지 모릅니다
✕대표자가 멋대로 합의해버리는 위험이 존재합니다
PACT AI 에이전트
✦복합 문제를 법령 레이어별로 분해 — 관할 기관·채널을 자동 설계AI
✦1단계 공식 통보 → 무응답 시 전 채널 동시 압박 → 법적 조치 자동 실행AI
✦기관 민원 + 국회의원 + 언론 + 공개 — 모든 방향이 동시에 터지는 구조AI
✓법 지식 없어도 됩니다. AI가 채널별 맞춤 문서를 자동 생성합니다
✓참여자 과반수 동의 없이는 누구도 임의로 합의할 수 없습니다
How It Works
상대방이 구조적으로 무시할 수 없습니다
단일 채널 순차 진행은 상대방이 하나씩 막으면 그만입니다. PACT는 처음부터 동시다발 구조로 설계되어 있습니다.
Phase 01
이슈 등록 & 집단 구성
문제를 입력하면 AI가 즉시 분해·분석합니다. 공유 링크로 같은 처지의 사람들이 모이고 서명·의견을 수렴합니다. 완전 무료입니다.
✦ 복합 이슈 분해✦ 동적 채널 매핑✦ 집단 의견 분석
↓ 집단 구성 완료 후 공식 통보 시작
1단계
공식 통보 (무료)
AI가 생성한 협상 요청서를 상대방에게 직접 전달합니다. 응답 기한을 명시하고 전달 기록을 자동 보관합니다.
✦ 채널별 문서 자동 생성✦ 전달 기록 보관
↓ 무응답 시 해결동참 (소액 분담) → 자동 에스컬레이션
2단계
동시다발 전 채널 압박
원클릭으로 모든 채널이 동시에 실행됩니다. 기관 공식 민원 + 지역구 국회의원 + 대통령실 국민제안 + 언론 보도자료 + 공개 페이지. 어떤 조직도 모든 방향을 동시에 감당하기 어렵습니다.
🏛 관할 기관 민원🏛 국회의원 멘션📰 언론 보도자료📢 공개 압박
↓ 무응답 시 법적 조치
3단계
법적 조치
내용증명 발송(AI 초안 + 전문가 검토), 집단소송 준비 패키지 자동 생성, 법무·노무법인 연결 중개.
📋 내용증명 초안⚖️ 집단소송 준비👨‍⚖️ 전문가 연결
↓ 어느 단계에서든 합의 시
합의 도출
참여자 과반수 동의로 확정
상대방이 협상에 응하면 AI가 합의문 초안을 자동 작성합니다. 참여자 과반수 동의 없이는 어떤 합의도 확정될 수 없습니다. 대표자 단독 합의는 구조적으로 불가능합니다.

✦ AI Agent Engine
PACT AI 에이전트, 8개 엔진으로 작동합니다
목표를 받으면 계획을 세우고, 문서를 만들고, 발송하고, 무응답이면 다음 단계를 자동 실행합니다.
Engine 01 ✅ 구현
복합 이슈 분해
Issue Decomposition
막연한 문제를 AI가 법령 레이어별로 자동 분해합니다.
Engine 02 ✅ 구현
동적 채널 매핑
Channel Mapping
이슈 분석 결과를 바탕으로 관할 기관·국회의원·언론사를 실시간 조합합니다.
Engine 03 ✅ 구현
채널별 문서 생성
Document Generation
협상 요청서·민원서·보도자료를 각 채널 형식에 맞게 자동 생성합니다.
Engine 04 ✅ 구현
집단 의견 분석
Opinion Analysis
수백 명 참여자의 의견을 자동 분류·집계해 핵심 요구사항 우선순위를 도출합니다.
Engine 05 ✅ 구현
합의문 생성
Agreement Generation
협상 경과와 요구사항을 바탕으로 합의문 초안을 자동 작성합니다.
Engine 06 ✅ 구현
증빙 분석
Evidence Analysis
증빙자료를 분석해 요약 텍스트를 생성합니다. 원본은 비공개 보관됩니다.
Engine 07 ✅ 구현
협상 전략 추천
Strategy Recommendation
상황에 맞는 협상 전략과 대응 시나리오를 제안합니다.
Engine 08 ✅ 구현
학습 기반 전략 추론
Strategy Inference Engine
축적된 판례·언론 보도·성공·실패 데이터를 학습한 AI가, 왜 안 됐는지부터 분석하고 실제로 통하는 전략을 설계합니다.
